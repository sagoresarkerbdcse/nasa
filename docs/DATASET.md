# FireCal Harmonized Active Fire Record (MODIS → VIIRS)

**Version {{VERSION}} · {{YEARS}} · released {{DATE}} · CC BY 4.0**

One consistent monthly record of active-fire activity for every country and every 1° cell on Earth, from 2003 onward. It is built from NASA FIRMS MODIS and VIIRS detections, with **MODIS-era values harmonized to VIIRS units, validated blind, and given 90% error bars**.

> Independent project for the NASA Space Apps Challenge 2026. Not affiliated with or endorsed by NASA. The underlying detections are from NASA FIRMS (ESDIS).

## Why this exists

MODIS (2000→) and VIIRS (2012→) both detect fires, but VIIRS's smaller pixels see 2–4× more. Stitching the two together naively creates a fake jump in 2012. MODIS is also near the end of its mission, and Terra's and Aqua's drifting orbits are changing what it sees. This dataset carries the 20-year MODIS fire record forward in VIIRS units, so long-term trends can be studied across the sensor change.

## What's inside

| Folder | Files | Format |
|---|---|---|
| `netcdf/` | Monthly and annual 1° grids: `harmonized_fire_days`, `*_lo90`, `*_hi90`, `source_flag` | NetCDF4, CF-1.8 / ACDD-1.3 |
| `cog/` | One annual map per year | Cloud-Optimized GeoTIFF, EPSG:4326 |
| `tables/` | `country_monthly.csv`, `country_annual.csv` (with FRE, CO₂, CO, PM2.5), `grid_1deg_annual.csv` | CSV |
| `model/` | Harmonization model, blind validation, MODIS detection-probability curves, orbit-drift analysis | JSON, CSV |
| `stac/`, `catalog.json` | Catalog of all assets | STAC 1.0 |
| `datapackage.json` | Machine-readable description of the tables | Frictionless Data |
| `quickstart.ipynb` | Load, plot, map, compare | Jupyter |
| `ATBD.md` | Full method, validation, limitations, references | Markdown |

**Unit:** *fire-days*, the number of unique ~1 km (0.01°) cells × days with at least one nominal- or high-confidence active-fire detection. VIIRS S-NPP observes it from 2012. Before 2012 it is MODIS harmonized to VIIRS units (`source_flag` = 0, with intervals).

## Key columns (`tables/country_annual.csv`)

| Column | Meaning |
|---|---|
| `country` | FIRMS country name, or `World` |
| `year` | Calendar year |
| `modis_fire_days`, `viirs_fire_days` | Raw fire-days per sensor |
| `harmonized_fire_days` | VIIRS-equivalent fire-days (observed from 2012, harmonized before) |
| `harmonized_lo90`, `harmonized_hi90` | 90% interval (harmonized years only) |
| `source` | `viirs_observed` or `modis_harmonized` |
| `fre_pj` (+ `_lo`, `_hi`) | Fire radiative energy, PJ |
| `dry_matter_tg` | Biomass burned, Tg |
| `co2_tg`, `co_tg`, `pm25_tg` (+ ranges) | Emissions, Tg. Conservative: no cloud correction |

## How good is it?

Blind test: the model is trained on some overlap years and predicts others as if VIIRS did not exist. The full table is in `model/validation.csv`. The monthly country-level median error is about **12–14%**, against about 36–39% with a single global ratio. The annual error is about **5–6%**. The 90% intervals contain about 85–91% of held-out values. Coverage is lowest for 2022–2024, the years of strongest Terra/Aqua orbit drift.
